MeshCore Vanity Key Generator

Generate Ed25519 keys with custom hex prefix/suffix patterns using your browser's computational power.

More workers = faster search (uses more CPU)

Attempts: 0 | Rate: 0/s

Keys are stored only in this browser (localStorage) and survive refresh.

How it works: This page uses Web Workers with libsodium WASM to search for Ed25519 keys in the background. Multiple workers run in parallel for maximum performance.

Tip: Shorter patterns are found faster. A 2-char prefix takes seconds; a 6-char pattern may take hours. More workers = faster search.

Note: For maximum performance with SharedArrayBuffer, deploy with COOP/COEP headers (see _headers file for Netlify).
